# Original material and organization

The project began as Desktop/A#01 with two PDFs and a ZIP of classroom fixtures. The folder is now Linux_CLI_Lab and uses a new Git repository on main.

| Original | Maintained location |
| --- | --- |
| CS-3002-Information-Security-A0.pdf | docs/original/Assignment_Brief.pdf |
| i222327-Mohammad Rohaan-A #0.pdf | docs/original/Original_Submission.pdf |
| CS3002_A0_Task_Files.zip | All ten extracted files under data/fixtures/ |

Every extracted file was compared byte for byte with its ZIP member before the redundant ZIP was removed. data/manifest.json records SHA-256 values. No large release assets are needed for this project.

The original submission has 24 pages. The brief has 48 pages. Both are retained as original course artifacts, with their content unchanged. The rebuilt report explains the maintained commands and includes the original submission as an appendix. Presentation figures capture the maintained local demo and use a standard size for the gallery.

The brief's screenshot rules apply to the original course submission. New portfolio figures are labeled as maintained-demo evidence. The original appendix preserves the submitted pages.

The classroom fixtures include a sample plaintext password field and a 16-line shortened wordlist. These values are educational input data. Real passwords should use an appropriate password-storage mechanism.

The expanded project handbook is generated from data/project_sections.json. tools/content_sections.py renders the same details into the README, existing website sections and report chapters.
